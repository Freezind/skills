# Skills

A collection of AI agent skills for Claude Code, Cursor, Copilot, Gemini CLI, and other AI coding assistants.

## Install

```bash
npx skills add Freezind/skills
```

## Available Skills

| Skill | Description |
|-------|-------------|
| `markdown-fetch` | Fetch and convert web pages to clean Markdown via markdown.new. Supports single-page fetch and multi-page site crawl. |
